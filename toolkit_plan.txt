PERSONAL MINI-TOOLKIT PLAN

Tool 1: Simple Calculator
The calculator asks the user for two numbers and an operation, then displays the answer.

Tool 2: To-Do List
The to-do list allows the user to add tasks, view tasks, and remove tasks from a changing list.

Tool 3: Number Guessing Game
The guessing game asks the user to guess a secret number and uses conditionals to tell them if their guess is too high or too low.

Tool 4: Name Formatter
The name formatter asks for a name and displays it in a clean, friendly format.
